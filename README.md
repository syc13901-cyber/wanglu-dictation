# 王陆语料库 · 雅思听力听写练习

单文件听写练习工具（`index.html`），基于 [zyxlele/wanglu-dictation](https://github.com/zyxlele/wanglu-dictation) 二次开发，无需构建、无后端，浏览器打开即用。

## 功能

- **32 个章节 · 5877 个单词**：第 3 章（特别名词）、第 4 章（形容词/副词）、第 5 章（吞音连读）、第 11 章（综合测试）
- **教材录音在线播放**：每个章节对应官方教材录音，流式加载（Alt+P 播放/暂停），支持 0.75~2 倍速
- **逐词朗读**：浏览器语音合成（en-GB）朗读单词，离线可用；点行号听当前词，结果页点错词重听
- **暂停续写**：进度自动保存（localStorage），可随时暂存退出、从断点继续，直到整轮完成；首页/章节页均有继续入口
- **分段批改**：批改与完成只统计已听写部分，未听写不计错；正确率按本次完成量计算
- **分段记录还原**：一轮分多次完成时，每次记录标注范围（如「词 1–5」），详情弹窗逐词还原当次正误与所填内容
- **错词本**：批改后错词即时收录（同轮不重复计次）；支持单词删除与整章清空；可只练错词
- **统计图表**：章节正确率趋势（折线 + 迷你走势图）、每次听写详情

## 使用

- 在线版：GitHub Pages 地址（见仓库首页 About）
- 本地：直接双击 `index.html` 即可；数据保存在当前浏览器 localStorage，换浏览器/设备不共享

## 词库与音频来源

- 词库数据源自王陆《雅思王听力真题语料库》，版权归原作者（王陆老师/出版社）所有，本工具仅限个人学习、非商用
- 教材录音来自开源仓库 [27rabbit-penguin/IELTS_repo](https://github.com/27rabbit-penguin/IELTS_repo)（在线流式播放，不随本仓库存储）
- 章节-录音映射参考 [ymir-twice/wanglu-dictation](https://github.com/ymir-twice/wanglu-dictation)

## 更新方式

修改本地 `王陆语料库听写练习_v5.html` 后，复制覆盖本仓库的 `index.html`，提交推送即可。
